This project is my practice ground for **Riverpod**, Flutter's reactive state management solution. Each part of the app demonstrates a core concept in a simple, clean way.

## 🚀 Features

- ⚡ Reactive state management with Riverpod
- 🧩 Clean, modular project structure
- 🎨 Simple and responsive UI
- 🔄 Providers for state, async data, and logic separation

## 🧠 What I Learned

| Concept | Description |
|---|---|
| `Provider` | Expose read-only values |
| `StateProvider` | Manage simple state |
| `NotifierProvider` | Handle complex state logic |
| `ref.watch / ref.read` | React to and read provider state |
<!-- | `FutureProvider` | Work with async data | -->
